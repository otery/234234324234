# Fold Reveal (갤럭시 Z 폴드8) — v5

아이폰 듀오의 펼침 애니메이션을, 폴드8에서 **루팅 없이 낼 수 있는 최대치**로 재현합니다.

## v5에서 무엇이 달라졌나 — "그럴듯함"에서 "정확함"으로

v4까지는 보기엔 그럴듯했지만 세 군데가 가짜였습니다. v5는 그걸 고칩니다.

### 1. 진짜 원근 투영 (가장 큰 변화)

v4는 "힌지에서 멀수록 비례해서 압축"하는 근사치였습니다. 적당히 접혔을 땐 괜찮지만
많이 접히면 실제 원근과 눈에 띄게 어긋납니다.

v5는 실제로 3D를 풉니다:
1. 화면 픽셀마다 카메라 방향으로 광선을 쏘고
2. 힌지를 축으로 회전한 두 반평면과의 교점을 구하고
3. 그 교점의 평면 내 좌표로 텍스처를 읽습니다

원근 단축, 기울기, 가장자리 수렴이 전부 물리적으로 맞아떨어집니다.
`uCameraDist` 로 광각/망원 느낌까지 조절됩니다.

### 2. 기기가 알려주는 실제 접힘선 사용

v4는 힌지를 화면 정중앙(x=0.5)이라고 가정했습니다. 폴드8은 와이드 폼팩터라 실제
접힘선이 정중앙이 아닐 수 있고, 플렉스 모드 상태에서도 달라집니다.

v5는 Jetpack WindowManager 의 `FoldingFeature` 로 실제 접힘선의 위치·방향을 읽어
셰이더에 그대로 먹입니다. 값을 못 받는 환경에서는 조용히 중앙/세로로 폴백합니다.

### 3. 법선 벡터 기반 실제 조명

v4는 거리에 비례한 임의 명암이었습니다. v5는 회전한 면의 실제 법선 벡터를 구해
램버트 확산 + 블린-퐁 스펙큘러를 계산합니다. 면이 광원을 향할 때 자연스럽게 밝아지고,
기울어질 때 광택이 표면을 훑고 지나갑니다.

### 4. 적응형 품질 제어

8탭 블러는 무겁습니다. v5는 매 프레임 실제 그리기 시간을 측정해서,
예산(7ms)을 넘기면 즉시 탭 수를 줄이고 여유가 생기면 천천히 올립니다.
**끊김 대신 약간의 디테일을 포기**하는 쪽을 택합니다.

### 5. 모션 블러도 물리적으로

v4는 화면 공간에서 옆으로 밀어 번지게 했습니다. v5는 각도 자체를 흔들어 샘플링해서,
실제 회전 궤적을 따라 번집니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `HingeAngleSensor.kt` | 힌지 각도(0~180°) 실시간 수신 |
| `FoldingFeatureTracker.kt` | 실제 접힘선 위치·방향·상태 추적 |
| `SpringAngle.kt` | 스프링 감쇠 — 움직임의 물성 |
| `FoldShader.kt` | AGSL 셰이더 — 원근 투영, 조명, 블러, 주름, 모서리 |
| `FoldTransitionView.kt` | vsync 렌더 루프 + 적응형 품질 제어 |
| `OverlayService.kt` | 실시간 캡처(더블 버퍼) + 전역 오버레이 + 커버 동기화 |
| `CoverPresentation.kt` | 커버 디스플레이 동기 표시 |
| `MainActivity.kt` | 권한 요청 / 시작·중지 / 미리보기 |

## 사용법

1. Android Studio에서 이 폴더 **Open** → Gradle Sync (인터넷 필요)
2. 폴드8 USB 연결 + USB 디버깅 → `Run ▶`
3. **"1. 오버레이 권한 요청"** → 설정에서 "다른 앱 위에 표시" 허용
4. **"2. 화면 캡처 권한 요청 + 전체 앱 효과 시작"** → 화면 기록 동의
5. 아무 앱이나 켜놓고 접었다 펼쳐보세요.

## 느낌 조절 가이드

### 움직임 — `FoldTransitionView.kt` / `SpringAngle.kt`

| 증상 | 만질 것 |
|---|---|
| 늘어지고 굼뜸 | `stiffness = 420f` **올리기** (예: 600) |
| 끝에서 출렁임 | `damping = 38f` **올리기** (예: 48) |
| 딱딱하고 기계적 | `damping` **내리기** (예: 30) |
| 손떨림이 보임 | `stiffness` 내리고 `damping` 올리기 |

### 원근감 — `FoldTransitionView.kt`

| 증상 | 만질 것 |
|---|---|
| 원근이 너무 과장됨 | `cameraDistance = 2.1f` **올리기** (예: 2.8) |
| 너무 평평해서 밋밋함 | `cameraDistance` **내리기** (예: 1.7) |
| 접힘이 얕음 | `FoldShader.kt` 의 `mix(82.0, 0.0, eased)` 에서 82 올리기 |

### 블러 — `FoldTransitionView.kt` / `FoldShader.kt`

| 증상 | 만질 것 |
|---|---|
| 너무 흐림 | `maxBlurVelocity = 260f` **올리기** |
| 블러가 안 보임 | `maxBlurVelocity` **내리기** (예: 160) |
| 번짐 폭 조절 | 셰이더 `radians(3.2)` |
| 성능 우선 | `frameBudgetNanos` 낮추기 (더 공격적으로 품질 감소) |

### 질감 — `FoldShader.kt`

| 조절 대상 | 상수 |
|---|---|
| 힌지 주름 진하기 | `crease * 0.40 * foldAmount` |
| 구석 그늘(AO) | `ao * 0.24 * foldAmount` |
| 광택 세기 | `0.20 + velocity * 0.12` |
| 광택 날카로움 | `pow(specAngle, 48.0)` — 올리면 더 좁고 선명 |
| 접힌 면 어두워짐 | `mix(0.62, 1.0, lambert)` — 0.62 내리면 더 극적 |
| 이징 | `mix(base, settle, 0.65)` |
| 모서리 둥글기 | `FoldTransitionView.kt` 의 `cornerRadiusDp = 22f` |

### 타이밍 — `OverlayService.kt`

| 조절 대상 | 상수 |
|---|---|
| 시작 민감도 | `START_DELTA_THRESHOLD = 3f` |
| 종료 시점 | `QUIET_TIMEOUT_MS = 260L` |

## 여기서 더 갈 수 없는 이유

아래는 구현을 덜 한 게 아니라, 안드로이드가 서드파티 앱에 권한을 주지 않는 영역입니다.
v5는 이 벽 바로 앞까지 간 상태입니다.

- **화면 녹화 아이콘을 끌 수 없음** — MediaProjection 사용 중 상태바에 강제 표시.
  프라이버시 보호용 OS 정책이라 우회하지 않았습니다.
- **`FLAG_SECURE` 화면은 캡처 불가** — 은행 앱, DRM 영상 등. 보안 기능이라
  우회 로직을 넣지 않았고, 해당 화면에서는 효과가 뜨지 않습니다.
- **캡처 → 렌더 1~2 프레임 지연** — 컴포지터가 직접 그리는 게 아니라 캡처본을
  다시 그리는 구조의 본질적 한계입니다. (v5에서 버퍼를 줄여 한 프레임 정도 개선)
- **커버 디스플레이가 항상 노출되지 않음** — 삼성이 별도 Display 로 내주지 않으면
  메인 오버레이만 동작합니다.
- **컴포지터 레벨 통합은 루팅 영역** — Magisk/LSPosed SystemUI 후킹이 필요하며,
  보증 무효·벽돌 위험·OS 업데이트마다 깨짐 문제로 범위에서 제외했습니다.
